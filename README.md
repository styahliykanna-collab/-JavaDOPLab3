## Опис проєкту

Розроблено Java-програму для аналізу потоку безпекових подій. Кожна подія містить IP-адресу, рівень небезпеки, опис і час виникнення.

Проєкт містить такі класи:

- `SecurityLog` — модель події, реалізована за допомогою `record`.
- `SecurityLogAnalyzer` — сервіс аналізу потоків безпекових подій.
- `Main` — демонстрація роботи програми.
- `SecurityLogAnalyzerTest` — модульні тести JUnit 5.

## Реалізовані методи

**1. findFirstCriticalEvent()**

Знаходить першу подію з рівнем `CRITICAL`. Використовує `filter()`, `findFirst()` та `Optional`.

**2. getLogsBeforeDeadline()**

Збирає події, доки їхній час менший за заданий дедлайн. Використовує `takeWhile()`. Для правильного відбору потік має бути впорядкований за часом.

**3. detectIpBursts()**

Використовує власний stateful `Gatherer` для виявлення серій послідовних подій від однієї IP-адреси. Обробка завершується після досягнення заданої кількості виявлень.

## Запуск програми

Необхідно встановити JDK 25 та відкрити термінал у кореневій папці проєкту.

Windows:

```cmd
gradlew.bat :app:run
```

Linux/macOS:

```bash
./gradlew :app:run
```

## Запуск тестів

Windows:

```cmd
gradlew.bat clean test
```

Linux/macOS:

```bash
./gradlew clean test
```

Результати тестування можна переглянути у файлі:

`app/build/reports/tests/test/index.html`
